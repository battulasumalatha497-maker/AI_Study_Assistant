# AI Study Assistant

AI Study Assistant is a Python-based Streamlit application designed to help students study and analyze documents.

## Features

- Upload PDF documents
- Upload DOCX documents
- Upload PPTX presentations
- View document content
- Display word and character counts
- Generate key points
- Generate study quizzes
- Generate multiple-choice questions and calculate scores
- Detect email addresses
- Detect phone numbers
- Detect LinkedIn profiles
- Detect skills
- Detect programming languages
- Answer general questions using TF-IDF and cosine similarity

## Technologies Used

- Python
- Streamlit
- PyPDF
- python-docx
- python-pptx
- Scikit-learn
- Regular Expressions

## Project Structure

- `ai.py` - Main application
- `AI_Study_Assistant_Project_Report.txt` - Project report
- `Title_Page.txt` - Project title page
