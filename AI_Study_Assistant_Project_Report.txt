ABSTRACT 

The AI Study Assistant is a web-based application developed to help students study and understand their learning materials more efficiently. The application allows users to upload PDF, DOCX, and PPTX documents and extracts the text from the uploaded files. 

The system provides several useful study features, including document viewing, word and character counting, key-point generation, study quiz generation, multiple-choice quiz generation with scoring, and question answering. It can also identify information such as email addresses, phone numbers, LinkedIn links, skills, and programming languages from the uploaded document. 

The application is developed using Python and Streamlit. PDF files are processed using the PyPDF library, DOCX files are processed using the python-docx library, and PPTX files are processed using the python-pptx library. The question-answering feature uses TF-IDF vectorization and cosine similarity to identify the most relevant information from the uploaded document. 

The main purpose of this project is to provide students with a simple and interactive tool for studying digital learning materials.

1. INTRODUCTION 

Education is becoming increasingly digital, and students use many electronic documents such as PDF files, Word documents, PowerPoint presentations, notes, and study materials. Reading and searching through large documents can take considerable time. Students may also find it difficult to quickly identify important information from their study materials. 

The AI Study Assistant is a web-based application designed to help students interact with their digital study materials in a simple and convenient way. The application allows users to upload PDF, DOCX, and PPTX documents and automatically extracts the text from them. 

After uploading a document, the system provides useful features such as document viewing, word and character counting, key-point generation, quiz generation, and question answering. It can also identify information such as email addresses, phone numbers, LinkedIn links, skills, and programming languages. 

The application is developed using Python and Streamlit. Natural language processing techniques such as TF-IDF and cosine similarity are used to find relevant information when the user asks a question. 

The main goal of the AI Study Assistant is to provide students with an easy-to-use study tool that helps them access and understand information from their learning materials more efficiently. 

2. PROBLEM STATEMENT 

Students often use PDF, DOCX, and PPTX files as study materials. Finding important information from these documents manually can take time, especially when the document contains a large amount of text. 

Traditional document viewers mainly allow users to read the content but do not provide dedicated study features such as key-point generation, quiz generation, or question answering. 

Students therefore need a simple application that can read their study materials and provide useful information in an interactive manner. 

The AI Study Assistant addresses this problem by allowing users to upload PDF, DOCX, and PPTX documents and providing features such as document viewing, key-point generation, quiz generation, information extraction, and question answering. 

The system aims to reduce the time required to search through study materials and provide students with a convenient tool for learning from their digital documents.

4. EXISTING SYSTEM 

In the existing system, students commonly use PDF readers, word processors, presentation viewers, and other document viewing applications to study their learning materials. 

These applications mainly provide basic features such as opening, reading, searching, and viewing documents. They generally do not provide an integrated set of study features such as automatic key-point generation, quiz generation, information extraction, and question answering. 

When students need specific information from a large document, they may have to search through the document manually. This can take time and may make studying less convenient. 

Therefore, there is a need for a simple application that combines document processing with useful study assistance features in a single interface. 

5. PROPOSED SYSTEM 

The proposed system is an AI Study Assistant developed as a web-based application using Python and Streamlit. The system is designed to help students interact with their digital study materials through a simple and user-friendly interface. 

Users can upload PDF, DOCX, or PPTX files to the application. The system extracts the text from the uploaded document and provides several study-related features. 

The proposed system provides document viewing, word count, character count, key-point generation, study quiz generation, multiple-choice quiz generation with scoring, and question answering. It can also identify information such as email addresses, phone numbers, LinkedIn links, skills, and programming languages. 

For general questions, the system uses TF-IDF vectorization and cosine similarity to compare the user's question with sections of the uploaded document and identify the most relevant information. 

The proposed system provides multiple study functions in one application and helps students access information from their study materials more conveniently.

8. SYSTEM ARCHITECTURE 

The AI Study Assistant follows a simple document-processing architecture. The user interacts with the application through a web browser, while the Streamlit application processes the uploaded document and provides the requested study features. 

The main flow of the system is: 

User 
   ↓ 
Streamlit Web Interface 
   ↓ 
Upload PDF / DOCX / PPTX 
   ↓ 
Document Text Extraction 
   ↓ 
Text Processing 
   ↓ 
Study Assistant Features 
   ↓ 
Results Displayed to User 

The major components of the architecture are: 

1. User Interface 

The Streamlit interface allows users to upload documents, view document information, generate key points, generate quizzes, and ask questions. 

2. Document Processing 

The system identifies whether the uploaded file is a PDF, DOCX, or PPTX file and extracts readable text from it. 

3. Text Processing 

The extracted text is divided into meaningful lines and processed for searching and information extraction. 

4. Information Extraction 

Regular expressions and keyword-based processing are used to identify emails, phone numbers, LinkedIn links, skills, and programming languages. 

5. Question Answering 

For general questions, TF-IDF vectorization and cosine similarity are used to compare the question with document content and identify the most relevant section. 

6. Result Display 

The processed results are displayed to the user through the Streamlit web interface.

10. IMPLEMENTATION 

The AI Study Assistant is implemented using Python and Streamlit. The application is designed to provide an interactive interface for uploading and studying digital documents. 

10.1 Application Setup 

The project is created using Python in a Windows environment. A Python virtual environment is used to install and manage the required libraries. 

10.2 Document Upload 

The Streamlit file uploader allows users to select PDF, DOCX, or PPTX files. After the file is uploaded, the application checks the file type and processes it accordingly. 

10.3 Text Extraction 

For DOCX files, the python-docx library is used to read paragraphs and extract their text. 

For PDF files, the PyPDF library is used to read each page and extract available text. 

For PPTX files, the python-pptx library is used to read slides and extract available text from slide content. 

10.4 Document Statistics 

After extracting the text, the application calculates the total number of words and characters and displays these values to the user. 

10.5 Key-Point Generation 

The extracted document text is divided into individual lines. The application selects available content lines and displays them as key points for quick revision. 

10.6 Quiz Generation 

The application selects useful lines from the uploaded document and creates quiz questions. The original document lines are provided as answers that can be viewed by the user. 

10.7 Information Extraction 

Regular expressions and keyword matching are used to identify emails, phone numbers, LinkedIn links, skills, and programming languages from the uploaded document. 

10.8 Question Answering 

When the user enters a general question, the application divides the document into text sections. TF-IDF vectorization is then applied to the sections and the user's question. 

10.9 Similarity Calculation 

Cosine similarity is used to calculate how closely the question matches each document section. The section with the highest similarity is selected as the answer when a relevant match is found. 

10.10 Multiple-Choice Quiz 

The application selects useful lines from the uploaded document and creates multiple-choice questions. Each question provides answer options, and the user selects an answer using radio buttons. After submission, the application compares the selected answers with the correct answers and calculates the final score. 

10.11 Result Display 

The final results are displayed through the Streamlit interface. The user can view document information, key points, study quiz questions, multiple-choice quiz questions and score, extracted information, and answers directly in the browser.

12. ADVANTAGES AND LIMITATIONS 

12.1 Advantages 

1. The application provides a simple and user-friendly interface. 

2. Users can upload PDF, DOCX, and PPTX study materials. 

3. The application extracts text automatically from uploaded documents. 

4. It provides word and character counts for the uploaded document. 

5. Key points can be generated for quick revision. 

6. Study quiz questions and multiple-choice questions can be generated from the uploaded content. 

7. Users can ask questions about the uploaded document. 

8. The application can identify emails, phone numbers, LinkedIn links, skills, and programming languages. 

9. TF-IDF and cosine similarity help identify relevant information for general questions. 

10. The application runs through a web browser using Streamlit. 

12.2 Limitations 

1. The question-answering system mainly identifies the most relevant text from the uploaded document rather than generating a fully developed answer. 

2. The quality of the results depends on the quality and structure of the uploaded document. 

3. Scanned PDFs without readable text may not be processed correctly. 

4. Quiz questions are generated from document content, so the quality of questions depends on the available text. 

5. The application does not currently provide advanced conversational AI capabilities. 

6. The system does not permanently store uploaded study materials.
